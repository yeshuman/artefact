# Artefact Conversation Flow

## Overview
A natural conversation system where Satori introduces travel-related artefacts, 
Ronin can focus on interesting locations, and the dialogue evolves around discovered places.
All responses are dynamically generated by the LLM based on context and system instructions.

## Components

### 1. Streaming Architecture
Two parallel streams provide real-time updates:

#### Mondo Stream
- Primary conversation between Ronin and Satori
- Messages with embedded artefact tags
- Real-time dialogue progression
- SSE endpoint: `/stream/mondo`
- All message content generated by LLM

Example Stream Event:
```json
{
    "type": "message",
    "author": "satori",
    "content": "<LLM generated content with artefact tags>"
}
```

#### Artefact Stream
- System events about artefact processing
- Detection and enrichment status
- Focus events and detail updates
- SSE endpoint: `/stream/artefacts`

Example:
```json
{
    "type": "artefact_detected",
    "id": "kyoto-gardens",
    "confidence": 0.95
}
```

### 3. Ronin's Artefact Interaction

#### Decision Making Process
```python
async def consider_artefacts(self, message: Message) -> Optional[RoninMessage]:
    """Analyze artefacts in Satori's message and potentially focus on one."""
    artefacts = message.get_artefacts()
    
    # LLM decision making with dynamic system prompt
    response = await self.llm_client.chat.completions.create(
        messages=[{
            "role": "system",
            "content": f"""
            You are {self.name}, interested in {', '.join(self.interests)}.
            Consider these locations: {[a.name for a in artefacts]}
            Based on your interests and travel style, decide if and why you want to 
            explore any of these places further.
            Respond naturally as if speaking to a guide.
            """
        }]
    )
```

#### Focus Simulation
```python
async def focus_on_artefact(
    self,
    mondo: 'Mondo',
    artefact_id: str
) -> 'RoninMessage':
    """Express interest in a specific artefact."""
    # Register focus event
    await mondo.register_artefact_focus(artefact_id, "ronin")
    
    # Generate focused question via LLM
    response = await self.llm_client.chat.completions.create(
        messages=[{
            "role": "system",
            "content": f"""
            You are {self.name}, interested in {', '.join(self.interests)}.
            You've just focused on {artefact_id}.
            Express your interest and ask a relevant question about this place.
            """
        }]
    )
    
    return await self.message(mondo, response.choices[0].message.content)
```

### 5. Implementation Classes

#### Mondo Extensions
```python
class Mondo:
    async def register_artefact_focus(
        self,
        artefact_id: str,
        focused_by: str
    ) -> None:
        """Record when an artefact becomes the focus."""
        await self.emit_event({
            "type": "artefact_focus",
            "artefact_id": artefact_id,
            "focused_by": focused_by,
            "timestamp": datetime.now().isoformat()
        })
        
        await self.request_artefact_details(artefact_id)
```
