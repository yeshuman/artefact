# Product Context

## Project Purpose
A sophisticated chat-based system that:
- Facilitates dynamic conversations between Satori (guide) and Ronin (seeker)
- Performs real-time entity/artefact detection during conversations
- Uses streaming for responsive interactions
- Enriches detected artefacts with real-world data
- Maintains natural conversation flow with personality-driven interactions

## Core Problems Solved
1. Entity Detection & Enrichment
   - Real-time entity detection in streaming text
   - API-based enrichment of detected artefacts
   - Progressive learning through conversations
   - Multi-source data integration

2. Natural Conversation
   - Dynamic personality management for Satori and Ronin
   - Cultural awareness and adaptation
   - Teaching/learning style evolution
   - Context-aware interactions

3. Real-time Processing
   - Streaming text processing
   - Live entity detection and markup
   - Async data enrichment
   - Progressive UI updates

## High-Level Functionality
- Real-time chat system with personality-driven interactions
- Entity detection and classification during conversations
- Artefact enrichment through external APIs
- Split-panel UI with chat and artefact details
- Session-based conversation tracking

## Target Behaviors
- Natural, flowing conversation between Satori and Ronin
- Real-time entity detection and highlighting
- Progressive artefact data enrichment
- Dynamic personality adaptation
- Responsive, streaming-first interface
